# MAS Cartesian Architect

**Система мультиагентной координации, которая находит единственную лучшую стратегию (ординар) через квадрат Декарта и 8 критериев аттестации.**

## Что это

При координации множества агентов возникает комбинаторный взрыв — каждый агент пытается учесть действия всех остальных, сложность растёт как O(N²). Вместо перебора всех комбинаций система группирует агентов, проецирует на квадрат Декарта, аттестует через 8 критериев и принимает бинарное решение: ординар или режект.

## Почему это

Полный перебор: O(N²). Система: O(K² × M), где K — размер кластера, M — количество кластеров. Вместо «что сделает каждый агент?» — «какая группа даёт ++?»

## Квадрат Декарта

         Y (выполнение) ↑
    -+   │   ++  ← ОРДИНАР
    ─────┼─────→ X (качество)
    --   │   +-

| Квадрант | Значение |
|----------|----------|
| ++ | Ординар — проходит все 8 критериев |
| +- | Качественное, но медленное |
| -+ | Быстрое, но плохого качества |
| -- | Режект — всё плохо |

## Статика (7 групп)

**01_static_cartesian.py** — проекция на квадрат Декарта. Показывает X, Y, квадрант и проваленные критерии.

**02_static_8criteria.py** — проверка через 8 критериев. Кто ординар, а кто нет.

Результат: hybrid — единственный в ++ и единственный ординар.

## Динамика (50 групп × 10 поколений)

**03_dynamic_cartesian.py** — эволюция распределения по квадрантам. Плохие отсеиваются, хорошие размножаются.

**04_dynamic_8criteria.py** — эволюция через 8 критериев. Количество ординаров растёт.

Результат: эволюция подтверждает hybrid как лучшего.

## Стратегии групп агентов

| Стратегия | Описание | Квадрант |
|-----------|----------|:---:|
| greedy | Жадный — быстро, плохое качество | -+ |
| genetic | Генетический — качественно, медленно | +- |
| swarm | Роевой интеллект — сбалансирован | ++ |
| hybrid | Комбинированный — лучший | ++ |
| auction | Аукционный — средне | ++/+- |
| ml_based | Машинное обучение — хорошо | ++ |
| random | Случайный — всё плохо | -- |

## 8 критериев аттестации

Решение проходит только если ВСЕ 8 критериев выше порога.

| № | Критерий | Вопрос | Параметр | Порог |
|:--:|----------|--------|----------|:-----:|
| 1 | Истинность | Это правда? | truth_score | 0.85 |
| 2 | Рациональность | Это логично? | rationality_score | 0.85 |
| 3 | Эффективность | Какой ценой? | efficiency_score | 0.60 |
| 4 | Эффектность | Это нужно? | effectiveness_score | 0.85 |
| 5 | Адаптивность | Не сломается? | adaptability_score | 0.60 |
| 6 | Этичность | Не навредит? | ethics_score | 0.90 |
| 7 | Осмысленность | Есть смысл? | meaningfulness_score | 0.70 |
| 8 | Живучесть | Выдержит удар? | resilience_score | 0.60 |

## Формулы

X = (Истинность + Рациональность + Эффектность + Осмысленность) / 4
Y = (Эффективность + Адаптивность + Живучесть) / 3

Проваленный критерий = 0. Ординар = все 8 ≥ порога.
